# SSH 远程文件夹实现计划

## 目标与方案

本地 DSH 保留模型、账号和聊天，把远程目录作为可选择的工作区，通过 SSH 直接读写文件。0.1.x 的远程完整 Host/iframe 方案不符合此目标，已在 0.3.0 的构建中移除。

宿主 DSH 0.2.1-rc.3 的 workspaceRegistry 使用本机 fs.realpath/stat 注册路径。为每个 SSH 目录建立空的本机身份目录，持久保存映射，然后在 ctx.fs、ctx.subprocess 公开服务边界路由已登记工作区。会话头由本地 DSH 管理；模型上下文使用远端路径。AsyncLocalStorage 隔离不同会话的远端路径解析。这里没有文件镜像和目录同步。

## 已完成阶段

1. 独立连接配置、主机信任、SSH/SFTP、Agent、私钥、临时密码、私钥口令、跳板机。
2. 新建工作区本地/远程选择、SFTP 浏览、最近目录、本地原生工作区注册及持久映射。
3. 远程文件系统：规范路径、元数据、目录列表、UTF-8/二进制读取、写入/编辑、原子替换、版本保护、只读与工作区边界。
4. 本地模型原生工具接入；远端 Python 文件搜索；ssh_exec 使用原生权限审批、输出限制、超时与进程组终止。
5. 工作区重连的认证队列、原位密码提示和取消；断线不会回退本地执行。
6. 原生文件页兼容；适配 better-sidebar 的原文件接口与目录观察协议，复用既有文件页及编辑器，移除独立 SSH 文件入口；优化连接配置、认证与目录选择 UI。
7. 真实 Linux 服务器文件与工具测试、本地真实 SSH 密码/UI 测试、软件安装测试、桌面更新、Git 提交。
8. 0.3.1 子智能体兼容修复：在公开 subagents.startActivation 入口解析 POSIX 目录，避免 Windows node:path 注入盘符；在原生子会话创建阶段建立远程目录作用域。保留原生创建、权限、父子关系与生命周期检查，并避免在原生取得父智能体生命周期持有前异步等待。
9. 0.4.0 原有侧栏终端兼容：按会话路由 Shell 列表、当前目录和终端创建；SSH 通道内的临时 Python PTY 监督进程提供输入/输出、缩放、前台进程组观察与中断、分阶段终止会话进程及退出码，继续使用原生终端界面和权限语义。

## 验收与边界

验证本地模型产生的 write/read/edit 结果实际位于远端，命令 pwd 属于远端目录，原生文件页与 better-sidebar 原有文件页可读回文件，本机身份目录保持空。验证 SSH Shell 的原生审批、密码错误重试与取消、软链接越界拒绝、版本冲突拒绝以及本地工作区不受影响。

宿主 Git 快照、better-sidebar 的 Git API 暂不支持，文件读写、编辑、上传及 Linux 原有侧栏终端已接入。相关本机执行路径拒绝回退。本轮不修改第三方插件或用户模型凭据，不自动推送或发布 Git；按用户要求只制作与测试，不更新当前安装或重启 DSH。
